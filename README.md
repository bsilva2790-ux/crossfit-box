# 🏋️‍♂️ CrossFit Box - Portfólio Frontend

Um site moderno, limpo e totalmente responsivo desenvolvido para um box de treinamento de CrossFit. O projeto foi construído com foco em performance, experiência do usuário (UX) e design limpo.

## 🔗 Acesso ao Projeto
Você pode acessar a versão online do site através do link:
👉[Acesse o site online aqui](https://bsilva2790-ux.github.io/crossfit-box/)

---

## 🚀 Tecnologias Utilizadas
Este projeto foi desenvolvido utilizando tecnologias web modernas sem dependência de frameworks pesados:
* **HTML5:** Estrutura semântica da página.
* **CSS3:** Estilização avançada (Flexbox, variáveis e animações customizadas).
* **JavaScript (Vanilla):** Funcionalidades dinâmicas, como o carrossel de imagens da seção Hero e o menu responsivo para dispositivos móveis.
* **Hospedagem:** GitHub Pages.

---

## ✨ Funcionalidades
* **Menu Fixo e Responsivo:** Navegação fluida com suporte a telas mobile (hamburguer menu).
* **Seção Hero Interativa:** Carrossel de imagens dinâmico com transições suaves.
* **Grade de Planos e Horários:** Layouts estruturados para fácil visualização das modalidades e valores.
* **Integração com WhatsApp:** Botões de contato direto para conversão de novos alunos.
